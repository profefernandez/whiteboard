# whiteboard

An AI-powered Node.js whiteboard app for mapping ideas and intersections.

## Features
- Picture upload onto the board
- Free-draw canvas
- Sticky notes and thumb-tack pinning
- Website and video sticky panels
- Word document export from whiteboard notes
- AI idea-intersection assistant with feedback loop
- Error handling and server-side logs (`logs/errors.log`, `logs/feedback.log`)
- Color-rich, 3D spine-inspired styling

## Run
```bash
npm install
npm start
```
Open `http://localhost:3000`.

## Test
```bash
npm test
```
